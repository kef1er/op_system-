# op_system

man, pwd, cd, mkdir, touch — навигация и создание
ls (обычный, -F, -l) — просмотр каталогов
rmdir, rm — удаление
vi, cat >, cat, more — создание и просмотр файлов
cp, mv — копирование и перемещение
cut — выборка столбцов
grep — поиск по шаблону со всеми спецсимволами
find — поиск файлов по критериям с -exec
